E04: Retrieval and Cited Answers

Users ask in plain language and get answers citing document versions they can open, or a clear uncited label.

Waves: W3 · Tickets: 10 · Stories: 5

User stories

  • US-04.1: As a company staff member, I want an answer with citations to specific document versions I can open, so that I can check the answer myself. Delivered by SB-301, SB-304, SB-306.
  • US-04.2: As a company staff member, I want answers with nothing to cite clearly labelled uncited, so that I know when to be sceptical. Delivered by SB-304.
  • US-04.3: As a security reviewer, I want nothing the asker cannot open to ever reach the model's context, so that permissions hold even if the model misbehaves. Delivered by SB-302, SB-303.
  • US-04.4: As a company staff member, I want to ask from the web or from our chat app, so that I don't change tools to get help. Delivered by SB-307, SB-308.
  • US-04.5: As a product owner, I want pilot feedback captured against each answer, so that we improve on evidence. Delivered by SB-305, SB-310, SB-311.
