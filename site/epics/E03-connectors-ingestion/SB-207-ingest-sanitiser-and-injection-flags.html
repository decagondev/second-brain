SB-207: Ingest sanitiser and injection flags

Field Value
Epic E03 Connectors and Ingestion
Wave / slice W2 / S2.3 Pipeline
Stories US-03.3
Manual sb-ingest(7)
Laws LAW-09
Depends on SB-206
Status In review

Why

Ingested text is untrusted input; treat it like user input to a shell.

Acceptance criteria

  • ✓Instruction-like content is flagged and wrapped as quoted data
  • Injection corpus triggers zero tool calls (eval)
  • ✓Flags visible in citations

Subtasks

  • ✓Update the man pages listed above first (manual first, P2)
  • ✓Sanitiser rules
  • ✓Injection corpus: evals/corpus/injection.json (JSON, because Go reads it with the standard library)
  • ✓Eval wired into CI: the corpus runs in make check (TestInjectionCorpus); the agent-level suite waits for the tool bus
  • ✓Write or extend the law tests: LAW-09
  • ✓Devlog entry, ledger and changelog updated

Progress

2026-11-19: the sanitiser is built (internal/core/ingest, sanitise.go) and wired into the pipeline. - Strip removes invisible format characters (Unicode Cf: zero-width, bidi, BOM), HTML comments, elements hidden by style (unclosed ones are dropped to the end), and alt or title text over 100 characters. - Flag marks instruction-like spans: overrides, new roles, chat-role markers, tool-call JSON, "don't tell the user", and query-string links to non-tenant domains. - Flags are stored per chunk and are what citations will show. Wrap makes a data block the content can't close. - The 16-case corpus (12 attacks, 4 benign look-alikes) passes.

LAW-09 has its first law test, red first, then green, and a pipeline without a sanitiser is caught. One law fix along the way: zero-width obfuscation doesn't hide text; stripping reveals it, so the law now requires it to be flagged rather than removed.

Left: "Injection corpus triggers zero tool calls (eval)" needs the agent runtime and tool bus (SB-405, SB-501). A canned mock answer would prove nothing, so this stays open.
