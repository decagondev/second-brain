2026-11-19: - ports.CursorStore, with a file adapter (internal/adapters/cursor/filestore) for development; cells keep cursors in their database. - ingest.Syncer.Once stores the new cursor only after the whole sync succeeded, and Run syncs every 60 s plus jitter. - internal/obs gains a Prometheus text registry (Metrics, served at /metrics) and Freshness, which exports sb_ingest_last_success_age_seconds and sb_ingest_sync_failures_total per tenant and connector. - A test fails the second fetch, checks the cursor didn't move, then resumes and checks both documents are indexed.
