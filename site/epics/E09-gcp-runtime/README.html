E09: Cells on GCP

A real cell runs on Google Cloud in its own project, with its schedules, metrics and verifier, and nothing in the core knows it's GCP.

Waves: W9 · Tickets: 8 · Stories: 4

User stories

  • US-09.1: As a factory operator, I want a cell to run on Cloud Run and Cloud SQL in its own project, so that companies get a real Second Brain, not a local one. Delivered by SB-901, SB-902, SB-903.
  • US-09.2: As a company IT operator, I want every schedule, metric and check to run inside the cell, so that sync, retention, reports and checks happen without anyone remembering. Delivered by SB-904, SB-905.
  • US-09.3: As a asker, I want to reach my company's brain at its own address and sign in even if we have no corporate IdP, so that every acquired company can use it from day one. Delivered by SB-906, SB-907.
  • US-09.4: As a maintainer, I want the W1 to W7 items that waited for a real cloud closed on a staging cell, so that v1 is finished, not just built. Delivered by SB-908.
