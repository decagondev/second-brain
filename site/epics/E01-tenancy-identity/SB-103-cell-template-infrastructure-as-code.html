SB-103: Cell template (infrastructure as code)

Why

Isolation is a property of the template, not of discipline.

Acceptance criteria

  • ✓Template creates database, index schema, vault namespace, KMS key, queue and region pin
  • ✓No resource is shared between two cells except the control plane
  • ✓Template has a test that stamps two cells and checks no shared resource ids
  • ✓Placement is a template parameter behind the Placement port; no account id is hard-coded; a test stamps cells into two different mock accounts (ADR-0015)

Subtasks

  • ✓Update the man pages listed above first (manual first, P2)
  • Write IaC module infra/cell/: deferred to the first cloud adapter, which picks its IaC tool (ADR-0018)
  • ✓Parameterise only by manifest fields
  • ✓Isolation test stamping two cells
  • ✓Document cell anatomy in sb-tenancy(7)
  • ✓Envelope key hierarchy: cell root key in KMS wraps data keys, so the root can be re-wrapped later
  • ✓Write or extend the law tests: LAW-02
  • ✓Devlog entry, ledger and changelog updated

Progress

2026-11-19: the user decided the cloud question: cells are cloud-neutral, with a local adapter now and AWS, GCP and Azure adapters later (ADR-0018). Built against that decision: - internal/core/cell declares the template (database, index schema, vault namespace, root key, queue), taking only tenant and region from the manifest. Stamp makes it real through the new ports.Placement and ports.Keys, and it is idempotent. - NewDataKey gives envelope encryption: data keys are wrapped under the cell root key. - internal/core/cell/celltest is the contract every adapter must pass: idempotent ids, no shared ids in the same or different accounts, and a data key that another cell's root key can't unwrap. - internal/adapters/placement/local passes the contract and refuses unreadable records ("unknown" is not "absent"), identity mismatches and unsafe names. - No account id appears anywhere. Cells are stamped into the mock accounts acct-a to acct-d.

LAW-02 gains a cell-level law test, TestLAW02_CellsShareNothing, which was red first (not implemented) and is green now. The red ratchet takes per-test lines so the retrieval-level test can stay red until SB-301.

2026-11-19: reviewed by the user; CI green. Done. The IaC module still waits for the first cloud adapter (ADR-0018); it is a subtask, not an acceptance item.
