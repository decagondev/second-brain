E61: Every Format, Every Language

The brain reads what's in scans, images and recordings, finds an answer whatever language it's written in, and is usable by everyone, while text a model read is always marked as such.

Waves: W60 · Tickets: 7 · Stories: 2

Planned 2026-11-27 after W58, with the user. The concept is in 24-prove-read-reach.md. Every ticket keeps to the rules there: no new service the cell must run, no new store, no new third-party Go module, at most one setting a feature, no new page, nothing widens what anyone sees, a person approves every write, the tree only narrows, agents are definitions in the release bundle, stored results are checked when read, every long run has a ceiling, one level of consultation, the AI label never comes off by itself, a rhythm only drafts and stops with its subject, a brief about a person draws only on what they published, lent access lasts one run and travels with its result, a label never drops, a model call stays in its region, a new vendor is an adapter against a recorded fake, and text the brain didn't read from the source itself carries the AI mark.

User stories

  • US-61.1: As anyone, I want scans, images and recordings cited like any document, marked as machine-read, so that knowledge outside text files isn't invisible. Delivered by SB-6101, SB-6102.
  • US-61.2: As anyone or a steward, I want to find and read answers in any language and use the brain with a keyboard or a screen reader, so that language and ability don't decide who gets an answer. Delivered by SB-6103, SB-6104, SB-6105, SB-6106, SB-6107.

Exit gate

  • Text read from a scan, image, recording or translation carries the AI mark wherever it is cited (LAW-28 green)
  • An ungated or out-of-region reading model is never called; with none set, the files are skipped and counted
  • A German question finds the English fixture policy; every string has all six languages; the accessibility check passes over every tab
  • Every law test still green; no new store or Go module; the transcribe profile is optional
