E05: Actions, Approvals, Audit and Kill Switches

Agents draft and propose; humans send and approve; every tool call is audited before it runs; anything can be switched off in seconds.

Waves: W4 · Tickets: 12 · Stories: 6

User stories

  • US-05.1: As a company staff member, I want the agent to draft a reply or a ticket update that I send, so that I save time without losing control. Delivered by SB-409.
  • US-05.2: As an approver, I want to see exactly what will run, against which system, before I approve, so that approval means something. Delivered by SB-405, SB-406, SB-407, SB-410.
  • US-05.3: As a company IT operator, I want to switch off any agent, connector or tenant instantly, so that I can stop harm first and investigate second. Delivered by SB-403, SB-404.
  • US-05.4: As an auditor, I want an append-only, tamper-evident record of every tool call, so that I can prove who did what. Delivered by SB-401, SB-402, SB-412.
  • US-05.5: As a company staff member, I want to be told plainly when an action did not run, so that I never act on a false 'done'. Delivered by SB-408.
  • US-05.6: As a security reviewer, I want secrets never to appear in prompts, logs or audit payloads, so that a log leak is not a credential leak. Delivered by SB-411.
