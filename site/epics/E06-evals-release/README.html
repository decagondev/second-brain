E06: Evals, Release and Supply Chain

No agent, prompt, policy or model change reaches a tenant without passing evals, and every running build is a signed build that passed the gate.

Waves: W0, W3, W5 · Tickets: 12 · Stories: 4

User stories

  • US-06.1: As a parent-org platform lead, I want no agent, prompt or model change to reach a tenant without passing evals, so that quality never regresses silently. Delivered by SB-015, SB-309, SB-501, SB-502.
  • US-06.2: As a security reviewer, I want to prove which build, prompts and model ran for any action, so that every incident is reconstructable. Delivered by SB-503, SB-504, SB-506, SB-509.
  • US-06.3: As a company IT operator, I want a bad release to roll back in one step, so that a bad day stays short. Delivered by SB-507, SB-508.
  • US-06.4: As a security reviewer, I want a CVE fix to be a rebuild that every tenant takes, so that no tenant is left on a vulnerable build. Delivered by SB-505, SB-507, SB-510.
