## Why

The UI is English only, though sovereign sites are mostly in the EU.

## Acceptance criteria

- [x] Every string the web UI shows is in a catalog (`web/src/i18n/`) with English, German and French; a test fails on a string outside it
- [x] The manifest's `language` sets the default; a person can switch, kept in their browser
- [x] Cell errors carry a code the UI translates; an uncited claim is marked in every language; axe passes in each

## Subtasks

- [x] Update the man pages listed above first (manual first, P2)
- [x] Catalog
- [x] Manifest field
- [x] Tests
- [x] Write or extend the law tests
- [x] Devlog entry, ledger and changelog updated

## Progress

2026-11-23: done in S22.1. `web/src/i18n/` holds the catalog (337 entries, English keys with German and French) and `t`, `tn`, `tj` and `errorText`; `i18n.test.ts` parses every component and fails on a shown string outside the catalog, an unknown or unused key, or a translation whose placeholders differ. The manifest's `language` (en, de, fr) is written into the page's `lang`; the picker keeps a person's choice in their browser. Error codes are translated; axe and the uncited-claim mark pass in each language (`languages.test.tsx`). Manuals: sb-tenant(5), sb-errors(7), sb-ask(3).
