## Why

The UI is English only, though sovereign sites are mostly in the EU.

## Acceptance criteria

- [ ] Every string the web UI shows is in a catalog (`web/src/i18n/`) with English, German and French; a test fails on a string outside it
- [ ] The manifest's `language` sets the default; a person can switch, kept in their browser
- [ ] Cell errors carry a code the UI translates; an uncited claim is marked in every language; axe passes in each
