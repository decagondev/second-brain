## Why

Managers prepare 1:1s by digging through updates, goals and action items by hand.

## Acceptance criteria

- [ ] The `one-on-one` rhythm drafts a brief before each recurring 1:1 from the report's published updates, goals, action items and waits, checked as the manager
- [ ] The report sees exactly the manager's brief and can add a line; it never rates or scores
- [ ] LAW-30 is a law test and goes green; a private ask, inbox item, routine or memory entry never appears

## Subtasks

- [ ] Update the man pages listed above first (manual first, P2)
- [ ] One-on-one rhythm
- [ ] Brief agent and eval suite
- [ ] Shared view
- [ ] Tests
- [ ] Write or extend the law tests
- [ ] Devlog entry, ledger and changelog updated
