## Why

Next quarter's goals are drafted from memory, and overlaps between departments surface late.

## Acceptance criteria

- [ ] Two weeks before quarter end each space gets cited draft goals from check-ins, at-risk goals and request themes
- [ ] A parent's stewards see children's proposed goals rolled up; a child they can't open shows counts only
- [ ] An overlap between departments is a flag, never a merge; goals start only when each steward publishes

## Subtasks

- [ ] Update the man pages listed above first (manual first, P2)
- [ ] Planning rhythm
- [ ] Goal draft agent and eval suite
- [ ] Roll-up and overlaps
- [ ] Tests
- [ ] Write or extend the law tests
- [ ] Devlog entry, ledger and changelog updated
