## Why

## Acceptance criteria

- [ ] `/` focuses the ask box, Ctrl or Cmd+Enter asks, Esc closes a panel and returns focus, and a skip link comes first

- [ ] A test drives ask, follow-up, save and the tabs with the keyboard only; axe in each language
