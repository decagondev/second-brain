# E52: Write It Down Together

> What the brain learns flows back to the sources, drafts are written together, and every answer points to exactly where it came from.

**Waves:** W51 · **Tickets:** 7 · **Stories:** 2

Planned 2026-11-25 after W49, with the user. The concept is in [21-guard-write-act.md](../../docs/21-guard-write-act.md). Every ticket keeps to the rules there: no new service the cell must run, no new store, no new third-party Go module, at most one setting a feature, no new page, nothing widens what anyone sees, a person approves every write, the tree only narrows, agents are definitions in the release bundle, stored results are checked when read, every long run has a ceiling, one level of consultation, the AI label never comes off by itself, a rhythm only drafts and stops with its subject, a brief about a person draws only on what they published, and lent access lasts one run and travels with its result.

## User stories

- **US-52.1**: As an *owner*, *steward* or *reviewer*, I want suggested edits to my sources, drafts we edit together, agents in comments and a record of who made each note, so that knowledge flows back and credit is clear. Delivered by SB-5201, SB-5202, SB-5203, SB-5204.
- **US-52.2**: As *anyone asking*, I want cites to the page or slide, branched conversations and `@` and `/` in the ask box, so that I can check answers and ask freely. Delivered by SB-5205, SB-5206, SB-5207.

- [ ] A suggested edit cites only what the owner can open, and nothing is written to a source
