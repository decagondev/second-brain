# E54: Know Who Can See

> A document shared too widely is noticed and held back before the brain spreads it, its label goes wherever its content goes, and everyone can see how far each agent reaches.

**Waves:** W53 · **Tickets:** 7 · **Stories:** 2

Planned 2026-11-26 after W52, with the user. The concept is in [22-see-steer-spend.md](../../docs/22-see-steer-spend.md). Every ticket keeps to the rules there: no new service the cell must run, no new store, no new third-party Go module, at most one setting a feature, no new page, nothing widens what anyone sees, a person approves every write, the tree only narrows, agents are definitions in the release bundle, stored results are checked when read, every long run has a ceiling, one level of consultation, the AI label never comes off by itself, a rhythm only drafts and stops with its subject, a brief about a person draws only on what they published, lent access lasts one run and travels with its result, and a label never drops while the brain never changes who can open a source.

## User stories

- **US-54.1**: As an *owner*, *steward* or *security lead*, I want documents shared too widely found, held back until the owner confirms, and widening announced, so that the brain never spreads a sharing mistake. Delivered by SB-5401, SB-5402, SB-5403, SB-5404.
- **US-54.2**: As *anyone*, an *agent owner* or a *security lead*, I want labels that travel with every answer, each agent's reach and a map of sensitive documents, so that sensitive content goes only where it should, including into agents. Delivered by SB-5405, SB-5406, SB-5407.

## Exit gate

- [ ] The fixture salary sheet shared with the whole domain is listed, held from everyone but its owner and stewards, and released only by the owner
- [ ] A label never drops: a confidential cite marks the answer and a channel mention goes to the person directly (LAW-32 green)
- [ ] Nothing changes a source's sharing; counts never name a group or title the reader can't see
- [ ] Every law test still green; no new store, service or Go module
